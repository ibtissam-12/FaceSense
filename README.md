# FaceSense – Real-Time Face Recognition & Emotion Analysis

## Overview

FaceSense is an AI-powered application for real-time face recognition and emotion detection using Deep Learning and Computer Vision techniques.

The project was developed to recognize facial expressions and classify emotions from live webcam streams.

## Features

- Real-time face detection
- Emotion classification
- Deep Learning models
- Live webcam prediction
- Interactive Streamlit interface

## Technologies Used

- Python
- TensorFlow
- OpenCV
- Streamlit
- NumPy
- Pandas

## Dataset

FER2013 Dataset

The dataset contains facial images classified into seven emotions:

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

## Models Evaluated

- CNN
- MobileNetV2
- ResNet50

## Methodology

1. Data preprocessing
2. Data augmentation
3. Model training
4. Transfer Learning
5. Fine-tuning
6. Evaluation

## Results

The best performance was obtained using ResNet50 with Transfer Learning.
